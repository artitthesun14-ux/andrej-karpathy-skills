# Handoff

Command: `/handoff`

สรุปเป้าหมาย สถานะ ปัญหาและวิธีแก้ วิธีที่ลองแล้วไม่ได้ผล การตัดสินใจ และขั้นตอนถัดไป เพื่อให้ session ใหม่ทำงานต่อได้ทันที โดยแยกข้อเท็จจริงจากสมมติฐานและไม่เปิดเผย secrets

บันทึกที่ `.ai/handoff/current.md` และ `.ai/handoff/sessions/YYYY-MM-DD.md` (ใช้ convention เดิมของโปรเจกต์ถ้ามี) ไม่ commit หรือ push เอง

รายละเอียดฉบับเต็มอยู่ใน [`skills/productivity/handoff/SKILL.md`](../../skills/productivity/handoff/SKILL.md)
