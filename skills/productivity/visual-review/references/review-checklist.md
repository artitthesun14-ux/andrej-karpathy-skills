# Visual Review Checklist

Read when reviewing a rendered presentation, animation, chart, or 3D scene.

## Static

- Composition: clear focal point, balanced weight, intentional whitespace.
- Typography: hierarchy obvious, sizes readable at viewing distance, line length sane, no orphaned words in headlines.
- Spacing and alignment: consistent margins, grid, gaps. Nothing clipped or overlapping.
- Color and contrast: text meets WCAG AA (4.5:1 body, 3:1 large). Color is not the only signal.
- Consistency: same roles look the same across slides or scenes.
- Images: sharp, correctly cropped, not stretched, purposeful.
- Charts: finding stated, axes honest, labels readable, units and source shown.

## Motion

- Purpose of each movement is clear (cause, result).
- Timing: not too fast to read, not so slow it blocks. Frequent actions are subtle.
- Easing matches entering, exiting, moving.
- Scene transitions keep spatial continuity.
- Only one focal motion at a time.
- Reduced motion path works and still communicates.

## Behavior

- Responsive: desktop, tablet, phone. No horizontal scroll, no overflow, text still readable.
- Navigation works by keyboard, click, and touch.
- Performance: smooth animation, no layout shift, 3D idle load acceptable, offscreen work paused.
- Visual bugs: flicker, z-fighting, clipped text, broken fonts, missing assets, console errors.

## Capture tips

- Screenshot per slide or state at 1440x900 and 390x844.
- For animation, capture start, mid, and end frames, plus the reduced-motion state.
