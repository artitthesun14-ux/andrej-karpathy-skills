# Visual Prototyping

Use:

Idea → Storyboard → Motion Sequence → Prototype → Run → Inspect → Iterate

## 1. Define the Moment
Describe:
- trigger
- starting state
- main change
- ending state
- user attention
- purpose

## 2. Storyboard
For complex motion:
1. Before
2. Trigger
3. Main movement
4. Supporting movement
5. Final state

Only include meaningful frames.

## 3. Motion Sequence
Specify:
- element
- from
- to
- duration
- easing
- delay
- relationship to other elements

## 4. Prototype
Build the smallest prototype that answers the design question.

## 5. Inspect
Check timing, easing, clutter, cause/effect, layout shifts, mobile behavior, and reduced motion.

## 6. Iterate
Make the smallest change that fixes the observed problem, then inspect again.

A prototype succeeds when the motion communicates the intended interaction clearly, not merely when it looks impressive.
