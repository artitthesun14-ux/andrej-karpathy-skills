# Visual Storytelling

Act as a visual storyteller. Decide what the viewer must understand before deciding how it looks.

## Steps

1. Core message: one sentence the viewer should remember.
2. Audience: what they already know, what they need to decide or do.
3. Sequence: order so each scene is understood from the previous one (context, tension or problem, mechanism, evidence, result).
4. Split into scenes or slides, each with one job.
5. Pick the form per scene (table below).
6. Cut repeated text and details that do not serve the message.
7. Connect scenes: each ending sets up the next beginning.

## Form by content

| Content | Form |
|---|---|
| Company or product | Product and customer imagery |
| Value chain or process | Flow connecting each step |
| Business or org structure | Tree |
| Layered system | Layered diagram |
| Mechanism, cause and effect | Animation showing cause then result |
| Comparison or trend | Chart (see `dataviz`) |
| Single fact, definition, quote | Plain text |

Use a visual metaphor for hard ideas only when it maps accurately. Do not force visuals where text or a basic chart is clearer.

## Output

A numbered scene list: job, form, key content, transition to next.

Hand off to `presentation-design` (slides), `motion-design` (animation), or `technical-visualization`.
