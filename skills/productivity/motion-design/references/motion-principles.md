# Motion Principles and Patterns

Read when planning storytelling animation, scene transitions, or explanatory sequences beyond simple UI state changes.

## Principles

- Timing: duration by distance, complexity, frequency. Frequent actions are short.
- Easing: ease-out to enter, ease-in to exit, ease-in-out for continuous movement.
- Staging: direct attention to one thing at a time.
- Anticipation: a small preceding cue before a large move.
- Follow-through: let related parts settle just after the main move, subtly.
- Spatial continuity: show where things come from and go to.
- Hierarchy: primary motion is larger or earlier, secondary is quieter.
- Rhythm: consistent beat across repeated motions.

## Animation for understanding

Define for each animation: initial state, action, state change, cause, result, final state. Show where data starts, what it passes through, what happens along the way, and its effect. Do not animate lines wandering with no cause.

## Types and when to use

| Type | Use for |
|---|---|
| Entrance and exit | Introducing or removing elements |
| Transform and morph | Showing one thing becoming another |
| Camera movement | Moving through a large or 3D space |
| Scroll-driven | Pacing a story by user scroll |
| Step-by-step explanation | Processes the viewer should follow in order |
| Mechanical | Parts that move because other parts move |
| Particle | Many small items (traffic, flow). Use Canvas |
| Data flow | Movement through a system with visible stages |
| Scene transition | Moving between slides or scenes with continuity |
| Interactive | Viewer controls state. Define states and actions first |
