# /ui-design (UI Design)

หลักการ: UI ทำให้ visual system สม่ำเสมอ

## Purpose

กำหนดสไตล์ภาพ, สี, ตัวอักษร, component ให้สอดคล้องเป็นระบบเดียวกันทั่วทั้งเว็บไซต์หรือ feature

## When to use

หลัง UX flow นิ่งแล้ว ก่อนสร้าง prototype

## Inputs

wireframe และ user flow จาก ux-design

## Outputs

hi-fi design, design tokens, component spec

## Workflow position

- ขั้นตอนก่อนหน้า: `/ux-design`
- ขั้นตอนถัดไป: `/prototype`

ดูภาพรวม workflow ทั้งหมดได้ที่ `README.md`
