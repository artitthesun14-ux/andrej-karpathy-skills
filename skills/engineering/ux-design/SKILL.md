# /ux-design (UX Design)

หลักการ: UX ทำให้ flow ชัด

## Purpose

ออกแบบ flow การใช้งาน, wireframe เชิงโครงสร้าง, และ information architecture ให้สอดคล้องกับ spec

## When to use

หลังมี spec ชัดเจนแล้ว ก่อนลงรายละเอียดภาพ UI

## Inputs

spec จากขั้นตอนก่อนหน้า

## Outputs

user flow, wireframe, information architecture

## Workflow position

- ขั้นตอนก่อนหน้า: `/to-spec`
- ขั้นตอนถัดไป: `/ui-design`

ดูภาพรวม workflow ทั้งหมดได้ที่ `README.md`
